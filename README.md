AdminTI9B 💻
Sistema web de administración y gestión de recursos de TI desarrollado para optimizar el control de inventario, equipos y usuarios en entornos tecnológicos. AdminTI9B proporciona una interfaz intuitiva para la gestión integral de activos informáticos, permitiendo un seguimiento eficiente de hardware, software y personal técnico.
Comenzando 🚀
Estas instrucciones te permitirán obtener una copia del proyecto en funcionamiento en tu máquina local para propósitos de desarrollo y pruebas.
Pre-requisitos 📋
Para ejecutar este proyecto solo necesitas:
- Un navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a internet (para recursos externos como Bootstrap, jQuery, etc.)
- Un editor de código (opcional, para modificaciones)
Instalación 🔧
El proceso de instalación es muy sencillo ya que se trata de un proyecto web estático:
Paso 1: Clona el repositorio en tu máquina local

Paso 2: Navega al directorio del proyecto
bashcd AdminTI9B
Paso 3: Abre el archivo principal en tu navegador
bash# Puedes abrir directamente index.html con tu navegador
